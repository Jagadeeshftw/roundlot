## Parameters

Everything [`quote`](/docs/quote) takes, plus:

| Name | Type | Description |
|---|---|---|
| `account` | address, required | The account that will sign the transactions and receive the output |
| `maxSlippageBps` | number, default 50 | Worst acceptable fill against the quote, 1–1000; sets `amountOutMinimum` or `amountInMaximum` |
| `tokenForm` | `raw` or `wrapped`, default `raw` | `raw`: the account holds or wants the xStock itself, which adds wrap or unwrap steps. `wrapped`: the ERC-4626 wrapper token |
| `deadlineSeconds` | number, default 600 | Seconds until the swap reverts, 60–3600 |

## Request

## The steps

Depending on side and token form, a plan is some of:

1. **approve**: only when the account's allowance is too low; existing approvals are skipped.
2. **wrap**: ERC-4626 `deposit` of the raw token, when selling the raw form.
3. **swap**: `SwapRouter02.multicall(deadline, [exactInputSingle | exactOutputSingle])`, so the swap reverts after the deadline.
4. **unwrap**: ERC-4626 `redeem`, when buying the raw form.

Each approve sits directly before the step that spends it. If the account holds too little of the first token spent, the plan still comes back, with a warning. How to run a plan is in [Executing a plan safely](/docs/executing-plans).

<Hint type="danger" title="Signing moves real funds.">
The steps are mainnet transactions. Check each `to`, `data` and the limits before you sign, and sign them in order.
</Hint>

## Errors

| Code | HTTP | When |
|---|---|---|
| `invalid_input` | 400 | A parameter is missing or malformed, including `account`; no payment is asked for |
| `unknown_symbol` | 400 | The symbol isn't NVDA, SPY or TSLA |
| `insufficient_liquidity` | 422 | The pool can't fill this size |
| `token_paused` | 422 | The issuer has paused transfers |
| `multiplier_change_pending` | 422 | A multiplier change activates within the deadline plus 60 s |
| `rate_limited` | 429 | More than 60 requests a minute from your IP |
| `payments_unavailable` | 503 | The facilitator isn't reachable; the free catalog still works |
| `upstream_error` | 502 | X Layer RPC or OKX market data failed; try again |

None of these are charged.
