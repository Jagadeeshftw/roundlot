## Parameters

| Name | Type | Description |
|---|---|---|
| `symbol` | string, required | NVDA, SPY or TSLA (NVDAx and wNVDAx forms accepted) |

## Request

The first call answers `402`; pay and repeat it. See [How x402 payments work](/docs/x402).

<Tabs>
<Tab label="REST">

```bash
curl -i "https://api.roundlot.0xo.in/v1/session?symbol=SPY"
```

</Tab>
<Tab label="MCP">

```bash
curl https://api.roundlot.0xo.in/mcp -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"session","arguments":{"symbol":"SPY"}}}'
```

</Tab>
</Tabs>

## Errors

| Code | HTTP | When |
|---|---|---|
| `invalid_input` | 400 | `symbol` is missing; no payment is asked for |
| `unknown_symbol` | 400 | The symbol isn't NVDA, SPY or TSLA |
| `rate_limited` | 429 | More than 60 requests a minute from your IP |
| `payments_unavailable` | 503 | The facilitator isn't reachable; the free catalog still works |
| `upstream_error` | 502 | X Layer RPC or OKX market data failed; try again |

None of these are charged.
