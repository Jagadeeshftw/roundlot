## Why only the catalog is listed

OKX.AI's A2MCP service cards name mainnet USD₮0 as the settlement token. Roundlot's paid tools settle on X Layer testnet during the hackathon, so only the free catalog is listed. The paid tools can be listed once mainnet payments are switched on.

## Calling it

The marketplace calls the endpoint as plain REST:

```bash
curl -X POST https://api.roundlot.0xo.in/v1/catalog -H 'Content-Type: application/json' -d '{"symbol":"NVDA"}'
```

The endpoint is Roundlot's own HTTP API, so it answers whether or not an OKX messaging daemon is running.
