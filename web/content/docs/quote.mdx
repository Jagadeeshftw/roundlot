<Hint type="info" title="Data on mainnet, payment on testnet.">
Prices come from X Layer mainnet (`eip155:196`); the $0.01 is paid in testnet USD₮0 (`eip155:1952`). Not investment advice.
</Hint>

## Parameters

| Name | Type | Description |
|---|---|---|
| `symbol` | string, required | NVDA, SPY or TSLA (NVDAx and wNVDAx forms accepted) |
| `side` | `buy` or `sell`, required | `buy` pays stablecoin for the xStock; `sell` is the reverse |
| `size` | decimal, required | Trade size, in the unit given by `sizeUnit` |
| `sizeUnit` | `usd` or `shares`, default `usd` | `usd` is stablecoin notional; `shares` are xStock tokens, one per underlying share |

## Request

The first call answers `402` with the price; pay it and repeat the same request. See [How x402 payments work](/docs/x402).

<Tabs>
<Tab label="REST">

```bash
curl -i "https://api.roundlot.0xo.in/v1/quote?symbol=NVDA&side=buy&size=250"
```

</Tab>
<Tab label="MCP">

```bash
curl https://api.roundlot.0xo.in/mcp -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"quote","arguments":{"symbol":"NVDA","side":"buy","size":"250"}}}'
```

</Tab>
<Tab label="onchainos">

```bash
onchainos payment quote "https://api.roundlot.0xo.in/v1/quote?symbol=NVDA&side=buy&size=250"
```

</Tab>
</Tabs>

## Errors

| Code | HTTP | When |
|---|---|---|
| `invalid_input` | 400 | A parameter is missing or malformed; no payment is asked for |
| `unknown_symbol` | 400 | The symbol isn't NVDA, SPY or TSLA |
| `insufficient_liquidity` | 422 | The pool can't fill this size |
| `token_paused` | 422 | The issuer has paused transfers |
| `rate_limited` | 429 | More than 60 requests a minute from your IP |
| `payments_unavailable` | 503 | The facilitator isn't reachable; the free catalog still works |
| `upstream_error` | 502 | X Layer RPC or OKX market data failed; try again |

None of these are charged.
