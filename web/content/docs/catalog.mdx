title: "catalog"
description: "Free. The xStocks Roundlot covers, their token and wrapper addresses, venues, every tool's price and parameters, and the two networks."
price: "Free"
---

## Parameters

| Name | Type | Description |
|---|---|---|
| `symbol` | string, optional | Return one symbol: NVDA, SPY or TSLA (NVDAx and wNVDAx forms accepted). Default: all three |

## Request

<Tabs>
<Tab label="REST">

```bash
curl -X POST https://api.roundlot.0xo.in/v1/catalog -H 'content-type: application/json' -d '{"symbol":"NVDA"}'
```

</Tab>
<Tab label="MCP">

```bash
curl https://api.roundlot.0xo.in/mcp -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"catalog","arguments":{}}}'
```

</Tab>
</Tabs>

## Errors

| Code | HTTP | When |
|---|---|---|
| `unknown_symbol` | 400 | The symbol isn't NVDA, SPY or TSLA |
| `rate_limited` | 429 | More than 60 requests a minute from your IP |
